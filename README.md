# ORG // QUIZ

Учебная realtime-платформа для квизов по дисциплине **«Основы российской государственности»**.

## Что уже есть

- вход студента по коду комнаты без отдельной регистрации;
- ФИО и учебная группа;
- преподавательская авторизация;
- создание игровой комнаты;
- случайное распределение по командам;
- ручное переназначение студента в команду;
- realtime-обновление состава, статуса и рейтинга;
- ответы студентов с серверной проверкой;
- правильные ответы не выдаются клиенту;
- 4 стартовых тематических квиза / 20 вопросов;
- адаптивный интерфейс для телефона и компьютера.

## Backend

Проект использует Supabase. Все таблицы квиза имеют префикс `org_quiz_`.
Ключи правильных ответов хранятся в непубличной схеме `quiz_private`.

## Локальный запуск

Проект не требует сборщика. Откройте через любой статический HTTP-сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация

Репозиторий рассчитан на GitHub Pages или любой статический хостинг.

## ORG Party — новые игровые режимы

Платформа поддерживает роли **Модератор** и **Участник**, командные комнаты, режим просмотра Модератора «как Участник», мультимедийные задания, голосования и раунды на выбывание.

Игровые механики включают: тесты, несколько ответов, порядок, сопоставление, баттл ответов, кейсы, шкалу позиции, облако мнений, ранжирование, командную защиту позиции, флаги, гимны, фото известных людей, фото мест, интерактивную карту регионов России, голосование и elimination-раунды.

### Карта

Локальный файл `data/regions.topojson` содержит 89 геометрий и перенесён из открытого проекта `prokopenkoad42-creator/karta-rossii`. В его README указаны исходные геоданные OSM/GADM и geoBoundaries. Четыре геометрии 2022 года имеют отдельный признак `new2022`; интерфейс визуально отличает их и показывает примечание о спорном международном статусе.

### Демонстрационные медиа

Демо-вопросы используют открытые материалы Wikimedia Commons (Albert Einstein Head, EiffelTower.jpg, La Marseillaise.ogg) и FlagCDN для демонстрации механик. В редакторе Модератор может заменить URL медиа своими материалами.
