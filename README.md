# ORG // QUIZ

Учебная realtime-платформа для квизов по дисциплине **«Основы российской государственности»**.

## Что уже есть

- вход студента по коду комнаты без отдельной регистрации;
- ФИО и учебная группа;
- преподавательская авторизация;
- создание игровой комнаты;
- случайное распределение по командам;
- ручное переназначение студента в команду;
- realtime-обновление состава, статуса и рейтинга;
- ответы студентов с серверной проверкой;
- правильные ответы не выдаются клиенту;
- 4 стартовых тематических квиза / 20 вопросов;
- адаптивный интерфейс для телефона и компьютера.

## Backend

Проект использует Supabase. Все таблицы квиза имеют префикс `org_quiz_`.
Ключи правильных ответов хранятся в непубличной схеме `quiz_private`.

## Локальный запуск

Проект не требует сборщика. Откройте через любой статический HTTP-сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация

Репозиторий рассчитан на GitHub Pages или любой статический хостинг.
