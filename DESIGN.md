# ORG Studio — дизайн-система 2026-10-22

Назначение: современное веб-приложение для преподавателя и участников, где главное — контент и действия, а не декоративный стиль.

Токены: фон #F7F8FA; поверхности #FFFFFF; основной текст #161B26; вторичный #707C8D; границы #E7EAF0; действие #245DD0; положительное состояние #168466; ошибка #C64F61.

Иерархия: заголовок + основное действие + вторичная метаинформация. Размеры действий минимум 44px, видимый клавиатурный фокус и reduced-motion. Исключены тяжёлые градиенты, clip-path и огромные декоративные превью.

Домашняя страница: основной текст, две CTA, форма вступления и ведущий — две роли. Демонстрационный интерфейс не содержит реальных игровых данных.

Кабинет: навигация в левой колонке на широком экране, наверху на планшете/телефоне. Ключевые кнопки не перемещаются в скрытые меню.

Библиотека: компактные наборы, вопросы в строках с миниатюрами только для контекста. Картинки остаются предметом проверки содержательности; дизайн не заменяет этот аудит.

Игровая логика, Realtime, ACL и начисление очков остаются в app.js и Supabase без изменений.
