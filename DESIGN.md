# ORG/PARTY — дизайн-система UI UX Pro Max (2026-10-22)

## Контекст
Образовательный соревновательный квиз: участник входит по коду; преподаватель ведёт игру, управляет банком, командами и аналитикой. 5–6 команд, таймер, комбо, банк силы, перехват, спасение, секретный раунд и финальная дуэль остаются механизмами приложения.

## Основание
Оригинальная база nextlevelbuilder/ui-ux-pro-max-skill: products.csv №121 «Trivia & Quiz Game», colors.csv №121, ui-reasoning.csv №121, UX Guidelines и SKILL.md. Направление: Vibrant & Block-based + Micro-interactions, но с сдержанным информационно-ориентированным кабинетом преподавателя. Выбранная визуальная концепция — спортивная типографическая редакционная структура: чистые светлые поверхности, энергичные синие действия, золотые акценты только для рейтинга/времени.

## Система токенов
- Холст `#F5F7FB`, поверхность `#FFFFFF`, граница `#DDE5F0`.
- Основной текст `#14233A`, вторичный `#5E6D82`.
- Основное действие `#2458ED`, hover `#1647CF`, мягкая подложка `#ECF2FF`.
- Соревновательный акцент `#F3BD45`; правильный ответ `#11805B`; ошибка `#C1374B`. Цвет не должен быть единственным сигналом.
- Гарнитура Manrope с резервом Inter и system sans (уже подключены в проекте); базовый размер 16 px; иерархия заголовков 27–82 px по назначению.
- Скругления 12–24 px, отступы 8/12/18/24/32/48/64 px. Реализация: `ui-ux-pro-max.css` после `studio-2026.css`.

## Архитектура
1. Главная: один оффер, два CTA, вход участника по коду и ролевая вкладка, три простых шага; исключена декоративная псевдоигра.
2. Участник: сначала вопрос, таймер и доступные ответы, затем статус команды, рейтинг и банк силы.
3. Преподаватель: Библиотека → Провести игру → Результаты; запуск комнаты через явную последовательность Комната → Команды → Готовность → Игра.
4. Все состояния: заметное нажатие, фокус, ошибки около полей, отключённые действия визуально отличимы, при 620 px первичные CTA видны без скрытых меню.

## Ограничения и проверка
- Доступность: контраст не менее 4.5:1 для основного текста, 44 px для касаний, клавиатурный :focus-visible, не полагаться на hover; reduced motion.
- Перформанс: без зависимостей, WebGL, новых изображений и тяжелых анимаций; изменяется только CSS и текст главной.
- Скрытое состояние `.hidden` сохраняет приоритет над сетками/панелями.
- Недопустимо менять app.js, Supabase, расчёт очков, роли, realtime и серверную проверку без отдельной функциональной задачи.
- Проверить на 390/768/1440 px: нет горизонтальной прокрутки, первичные кнопки видны; визуально сверить главную, библиотеку, проведение игры, экран участника. Без авторизованной сессии live-часть требует отдельной сквозной проверки.
